# Open 4 Peer Review — Mask’d

Capstone project website documenting how Team Mask’d researched, designed,
built, and tested the Open 4 Peer Review Hub.

The Hub turns fragmented OER evaluation into a structured, evidence-based
workflow—making feedback actionable for authors and review outcomes visible to
future adopters.

## Run locally

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project structure

- `app/` — website pages and shared UI
- `public/assets/` — product screenshots, diagrams, illustrations, and team assets
- `tests/` — rendered-output verification
